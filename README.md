# COLHEITA ZERO — versão beta (MSX2)

**O dia em que o açaí acabou.** Aventura em Belém do Pará pós-apocalíptica, para MSX2. Ver-o-Byte Studios.

## ▶ Jogar no navegador

**[Clique aqui para jogar no WebMSX](https://webmsx.org/?MACHINE=MSX2E&DISK=https://raw.githubusercontent.com/passaroii/colheita-zero/main/COLHEITA_ZERO.DSK)**

O MSX liga sozinho e o jogo começa depois da logomarca (uns 20 segundos). Deixe a aba do jogo à vista: com ela escondida, o navegador deixa o emulador lento.

## Como jogar

- **Clique na tela do emulador** antes de usar o teclado.
- No começo: **1** = Sobrevivência (com fome e pontos), **2** = Exploração. Depois de escolher, aguarde: a primeira tela demora um pouco para carregar.
- **Setas ↑↓** escolhem a ação no menu, **ENTER** confirma, **ESC** volta.
- Prefere digitar? Aperte uma letra e escreva o comando (ex.: `PEGUE A FACA`).
- O SALVAR só vale enquanto a página estiver aberta.
