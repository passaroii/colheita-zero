# A Última Fome — versão beta (MSX2)

Aventura em Belém do Pará pós-apocalíptica, para MSX2. Ver-o-Byte Studios.

## ▶ Jogar no navegador

**[Clique aqui para jogar no WebMSX](https://webmsx.org/?MACHINE=MSX2E&DISK=https://raw.githubusercontent.com/passaroii/ultima-fome-beta/main/ULTIMA_FOME_D.DSK)**

O MSX liga sozinho e o jogo começa depois da logomarca (pode levar uns 20 segundos).

## Como jogar

- **Setas ↑↓** escolhem a ação no menu, **ENTER** confirma, **ESC** volta.
- Prefere digitar? Aperte uma letra e escreva o comando (ex.: `PEGUE A FACA`).
- No começo: **1** = Sobrevivência (com fome e pontos), **2** = Exploração.
- Clique na tela do emulador antes de usar o teclado.
